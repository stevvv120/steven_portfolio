# Steven — IT Developer Portfolio

Website portofolio responsif dengan HTML, CSS, dan JavaScript murni.

## Jalankan secara lokal
1. Ekstrak ZIP.
2. Buka folder `steven-portfolio`.
3. Buka `index.html` di browser. Untuk pengalaman pengembangan yang lebih nyaman, gunakan ekstensi Live Server di VS Code.

## Publikasikan gratis dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `stevvv120.github.io` untuk alamat utama atau repository biasa seperti `portfolio`.
2. Upload isi folder ini (`index.html`, `style.css`, `script.js`, `README.md`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu deployment selesai dan buka URL yang ditampilkan GitHub Pages.

## Sebelum dipublikasikan
- Periksa semua deskripsi proyek agar sesuai dengan kondisi kode saat ini.
- Tambahkan PDF CV Anda dan hubungkan tombol Unduh CV di `index.html`.
- Ganti tautan LinkedIn generik dengan URL profil LinkedIn Anda.
- Jika ingin mencantumkan email, tambahkan alamat email profesional yang memang ingin dipublikasikan.
- Untuk proyek yang belum memiliki demo online, tautkan ke repository GitHub saja.
